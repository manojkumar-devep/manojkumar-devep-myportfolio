03. Selection Sort

Live trace pass 1 · comparisons 0
sorted current minimum comparing

You're given an array arr of n integers. Sort the array in ascending order using the Selection Sort algorithm, and return the sorted array.

Selection sort divides the array into a sorted part (on the left) and an unsorted part (on the right). On every pass, it scans the unsorted part to find the smallest element and swaps it into the next position of the sorted part — one element locks into place per pass.

Examples

Input:arr = [64, 25, 12, 22, 11]
Output:[11, 12, 22, 25, 64]
Explain:Each pass pulls the smallest remaining value to the front.
Input:arr = [5, 1, 4, 2, 8]
Output:[1, 2, 4, 5, 8]

Constraints

  • 1 ≤ n ≤ 10^4
  • -10^5 ≤ arr[i] ≤ 10^5
  • Sort in-place with O(1) extra space

Complexity

  • Time: O(n^2) for all cases (best, average, worst)
  • Space: O(1)
Use two nested loops. The outer loop fixes the boundary between sorted and unsorted regions. The inner loop scans the unsorted region to track the index of the smallest value, then swap it with the boundary element once the inner loop finishes.
